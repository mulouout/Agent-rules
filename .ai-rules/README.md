# .ai-rules 目录说明

> 本目录存储 AI 协作规则系统的运行时配置。

## 文件说明

| 文件 | 作用 | 自动生成 |
|------|------|---------|
| `path.lock` | 记录项目路径和敏感授权状态 | ✅ 由 AI 自动创建/更新 |
| `path.lock.template` | 路径锁定文件模板 | ✅ 随项目发布 |

## path.lock 格式

```json
{
  "project_root": "项目根目录绝对路径",
  "initialized_at": "初始化日期",
  "rules_version": "规则版本号",
  "sensitive_auth": {
    "各项敏感信息的授权状态"
  }
}
```

## 工作原理

1. AI 每次启动时读取 `path.lock` 中的路径
2. 与当前项目路径对比
3. 如果路径变化，自动重置所有敏感授权
4. 重新询问用户同意后，更新 `path.lock`

## 注意事项

- 此目录下的文件由 AI 自动管理，一般不需要手动修改
- 不要将此目录提交到公开仓库（如果包含敏感信息）
- `path.lock.template` 是模板，可以提交到仓库
