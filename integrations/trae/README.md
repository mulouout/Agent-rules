# TRAE 接入指南

## 接入方式

### 方式一：规则文件引用（推荐）

在项目的 `.trae/rules/` 目录下创建一个规则文件（如 `ai-collab-rules.md`），内容如下：

```markdown
# AI 协作规则引用

> 本项目所有 AI 协作规则以项目根目录下的 AGENTS.md 为准。

## 必读文件

1. 先读取项目根目录下的 `AGENTS.md` — 核心行为准则
2. 再读取 `USER_PROFILE.md`（如果存在）— 用户偏好
3. 最后读取 `README.md` — 项目背景

## 注意事项

- 所有操作必须遵守 AGENTS.md 中的规定
- 修改规则必须同步更新 AGENTS.md
- 用户画像以 USER_PROFILE.md 为准
```

### 方式二：直接复制

将 `AGENTS.md` 的内容复制到 `.trae/rules/` 目录下的规则文件中。

> 不推荐此方式，因为后续更新规则时需要手动同步。

## 验证

在 TRAE 中打开项目后，问：
> "你知道在这个项目里不能用什么方式修改已有文件吗？"

如果回答"不能用写入工具覆盖已有文件，只能用编辑工具修改"，说明接入成功。

## 同步更新

当 AGENTS.md 更新时，请同步更新 `.trae/rules/` 下的相关规则文件，或确保规则文件引用了 AGENTS.md。
